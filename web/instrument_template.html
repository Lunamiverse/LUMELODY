Sound library

Every sound is original synthesis from the LUMI engine, the same C++ code that runs inside the plugin, compiled for the browser. Each key is synthesized at its own pitch, so nothing is a stretched sample. Real acoustic piano, guitar, brass, orchestral strings and Brazilian percussion still need licensed or recorded sources; the guitar, string, choir and horn sounds here are synthesized and labelled that way.
