LUMI MELODY

First round of sounds for the instrument. Play each one, then mark it Keep, Improve or Drop and leave a note on what to change. Your marks save automatically and I can read them back to tune the next round.

What you are hearing: 50 presets, all original synthesis from the LUMI engine (the same C++ code that will run inside the plugin). Each plays a short original phrase, loudness-matched so you compare sound, not volume. Not included yet: real acoustic piano, guitars, brass, orchestral strings and Brazilian percussion. Those need licensed or commissioned recordings; the guitar and string sounds here are synth models and are labelled that way.
