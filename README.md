# LUMI MELODY

Premium virtual instrument + melody generator for FL Studio (VST3, Windows/macOS; AU evaluated for macOS).

## Status (honest)

| Area | State |
|---|---|
| Sound engine (`engine/LumiEngine.h`) | **Working**, framework-free C++17. Layers: analog VA (PolyBLEP + unison), FM (2 modulators + feedback), Karplus-Strong string model, modal mallets/bells, filtered noise, formant voice, grain cloud. Per-voice SVF filter + envelopes, glide/mono legato, vibrato, LFO, pitch envelope, pitch bend, de-clicked voice stealing. FX: saturation, bit/rate crush, EQ, chorus, ping-pong delay, FDN reverb, tempo pump, stutter, width. |
| Presets (`presets/*.json`) | **50 original synthesis presets**, each with name, category, genre tags, description, use, playable range and a measured loudness trim. |
| Offline renderer (`tools/render`) | **Working**, used to make audition previews. |
| Preview pipeline (`tools/previews`) | **Working**: renders original demo phrases, checks clicks/NaN/spectrum, loudness-matches to -16 LUFS / -1 dBTP. |
| JUCE plugin (VST3/AU) | **Not started.** Next step. |
| Melody generator | **Not started.** |
| DETECT (loop analysis) | **Not started.** |
| Drums | **Not started.** |
| Recorded instruments | **None.** Acoustic piano, guitars, brass, orchestral strings and Brazilian percussion require licensed or commissioned recordings. The guitar/string presets here are synthesized models and are labelled as such. |
| DAW testing | **Not done.** Nothing has been tested in FL Studio yet. |

## Build the previews

```sh
g++ -O2 -std=c++17 tools/render/render_preset.cpp -o build/render_preset
python3 tools/previews/build_previews.py          # all presets
python3 tools/previews/build_previews.py halo     # only presets whose id contains "halo"
```
Requires numpy, scipy and ffmpeg. Preset sources live in `tools/previews/preset_defs.py`; demo phrases in `tools/previews/phrases.py`.
